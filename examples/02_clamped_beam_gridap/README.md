# 02 — Clamped-clamped beam (Gridap.jl backend)

## Model

Same clamped-clamped beam as example 01 (St. Venant-Kirchhoff, cubic nonlinearity),
assembled with Gridap.jl. Mesh: `clamped_clamped_beam.msh` (40×3×1 Hex8, quadratic
Lagrange, ~4977 free DOFs). Shared mesh with example 01.

## How to run

```bash
julia --project=examples/02_clamped_beam_gridap -e '
  using Pkg; Pkg.develop(path="."); Pkg.instantiate();
  include("examples/02_clamped_beam_gridap/main.jl")'
```

## Expected outputs

```text
results/
  summary.txt              — model description, eigenfrequencies, timing, Julia version, git commit
  data/
    W.jls                  — parametrisation (serialised)
    R.jls                  — complex reduced dynamics (serialised)
    R_coefficients.csv     — reduced dynamics coefficients, one row per non-zero monomial
    equations.txt          — realified reduced dynamics in human-readable equation form
  figures/                 — (empty; no figures generated by this example)
```

## Reference results

Curated reference outputs live in `results/reference/` (tracked in git).
Run `validate.jl` after a fresh run to compare against them:

```bash
julia --project=examples/02_clamped_beam_gridap validate.jl
```

## Approximate runtime

~5–10 minutes depending on hardware (order-3 parametrisation, Gridap assembly).

## Notes

Use this example alongside example 01 to cross-validate the Ferrite and Gridap
FEM backends. Both should produce the same `R_coefficients.csv` to within numerical tolerance.
