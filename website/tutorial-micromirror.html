Scanning torsional micromirror

We reduce a 412 308-DOF FE model of a 1×1 mm² silicon torsional micromirror to a four-equation ROM, then continue the frequency-response curve through its 1:2 parametric-resonance window. End-to-end runtime: under thirty seconds on a laptop.

FIG · 01 Geometry & first two torsional modes. The 1:2 ratio is the key: it activates a parametric-resonance branch the linear ROM cannot see.
Target API — not yet runnable
This tutorial is written against the planned high-level API (FEModel, parametrise, continuation) which is still under development. The code blocks below show what the workflow will look like. For a working entry point today, see the current API docs and the demo scripts.

What you will build

By the end of this tutorial you will have:

  • An FE model of a torsional micromirror loaded from a Gmsh mesh.
  • A 4-equation ROM that captures the 1:2 internal resonance between the first two torsional modes.
  • A continued frequency-response curve showing the parametric-resonance pocket and the pull-in fold.
  • A reconstruction of the physical mirror tilt $\theta(t)$ from the ROM trajectory.
Prerequisites

Julia ≥ 1.10, Ferrite.jl ≥ 1.0, BifurcationKit ≥ 0.4, Plots.jl. Install MORFE.jl from GitHub (not yet registered):

using Pkg; Pkg.add(url="https://github.com/MORFEproject/MORFE.jl.git")
(@v1.11) pkg> add Ferrite BifurcationKit Plots
01

Load the mesh and assemble FE operators

The mesh ships with the package as examples/micromirror.msh. We load it through the FEModel wrapper and request the matrices and tensors of the geometrically nonlinear St-Venant–Kirchhoff model.

using MORFE, Ferrite, Plots

# Load mesh and define FE problem (quadratic tetrahedra)
model = FEModel(joinpath(pkgdir(MORFE), "examples/micromirror.msh");
                 order=2,
                 material=SVK(E=170e9, ν=0.28, ρ=2330.0),
                 bc=[Clamp("anchor_left"), Clamp("anchor_right")])

M, C, K, G, H = assemble_nonlinear(model; damping=Rayleigh(0.0, 2e-9))

@info "DOFs = $(size(M, 1))   nnz(K) = $(nnz(K))"
# [ Info: DOFs = 412308   nnz(K) = 18 994 102

Material parameters target a typical CMOS-MEMS silicon process; Rayleigh damping was matched to a measured Q-factor of $\approx 4500$ on the first mode.

02

Inspect the linear spectrum

Before parametrising, look at the eigenpairs around the operating frequency. MORFE wraps a thick-restart Lanczos in linear_modes:

spectrum = linear_modes(M, K; n=8)

for m in spectrum
    println(@sprintf("  mode %d   ω = %.3f kHz   shape = %s",
                     m.id, m.ω/2π/1e3, m.label))
end
#   mode 1   ω = {ω₁} kHz   shape = torsion-1
#   mode 2   ω = {ω₂} kHz   shape = torsion-2          ← 1:2 with mode 1
#   mode 3   ω = {ω₃} kHz   shape = bending-out
#   mode 4   ω = {ω₄} kHz   shape = torsion-3
Spotting the resonance

Mode 2 has frequency $\omega_2 \approx 2\,\omega_1$, so any cubic non-linearity will couple them. We must include both modes in the master subspace, or the ROM will silently miss the parametric branch.

03

Declare the master subspace and parametrise

We pick modes 1 and 2 as masters. Each mode contributes a complex conjugate pair, so the manifold is 4-dimensional. Order 7 is the recommended default — ample for the $\theta < 12°$ range we care about.

master = [1, 2]      # torsion-1 & torsion-2

forcing = Harmonic(ω=2π*24e3, F=1.4e-4, mode=1)

rom = parametrise(M, C, K, G, H;  # target API
                  master=master,
                  order=7,
                  forcing=forcing,
                  tol=1e-3)

summary(rom)

The summary tells you what MORFE inferred about resonances:

# MORFE.ROM
#   master modes        : [1, 2]
#   manifold dimension  : 4
#   expansion order     : 7
#   monomials retained  : {n} (of {total})
#   resonances detected : 1:2 between modes 1 and 2  ←
#   wall-time           : {t} s

The reduced vector field — projected onto its real normal coordinates $(q_1, p_1, q_2, p_2)$ — is symbolically:

$$\dot q_1 = p_1, \quad \dot p_1 = -\omega_1^2 q_1 - 2\zeta_1\omega_1 p_1 + a_{112}\,q_1 q_2 + a_{122}\,q_1 q_2^2 + \dots$$ $$\dot q_2 = p_2, \quad \dot p_2 = -\omega_2^2 q_2 - 2\zeta_2\omega_2 p_2 + b_{111}\,q_1^2 + b_{222}\,q_2^3 + \dots$$

The $a_{112} q_1 q_2$ term is the parametric coupling that the 1:2 resonance keeps in the normal form. With single-mode reduction it would not exist.

04

Continue the frequency response

The ROM is a system of four ODEs. We hand it to continuation, which uses BifurcationKit’s collocation method to follow the periodic-orbit branch.

frf = continuation(rom;
                       ω_range=(2π*22e3, 2π*26e3),
                       amplitude_init=1e-3,
                       detect_bifurcations=true)

println("  branches found: $(length(frf.branches))")
println("  bifurcations  : $(frf.bifurcations)")
#   branches found: {n_branches}
#   bifurcations  : [Fold @ {ω_fold1}, Fold @ {ω_fold2}, NS @ {ω_ns}]
FIG · 02 Continued FRF. Two folds bound the bistable hysteresis window; the green branch is the 1:2 parametric resonance activated by mode 2.
05

Reconstruct the physical mirror tilt

The ROM lives in normal coordinates. To recover the physical tilt $\theta$, evaluate the parametrisation at a chosen DOF:

tip_node  = find_node(model, [0.5e-3, 0.0, 10e-6])
θ(z)      = reconstruct(rom, z; node=tip_node, component=3)

# Time-march the ROM at the resonant frequency
sol = simulate(rom; Ω=2π*24.18e3, tspan=(0, 2e-3))

plot(sol.t*1e3, rad2deg.(θ.(sol.u));
     xlabel="t [ms]", ylabel="θ [°]")

The reconstruction call traverses $\boldsymbol{\Psi}$ and contracts only the rows for the requested node — no million-DOF intermediate is allocated.

06

Validate against the FE reference

The package ships a small set of FE time-march snapshots for this geometry. validate compares peak amplitudes branch by branch.

ref = load_reference("micromirror_FOM")   # 14 reference points
err = validate(frf, ref)

@info "max relative error : $(round(err.rel_max*100, digits=3)) %"
@info "mean relative error: $(round(err.rel_mean*100, digits=3)) %"
# [ Info: max relative error : {error_max} %
# [ Info: mean relative error: {error_mean} %
That’s within FE discretization noise

Refining the FE mesh changes the reference more than the ROM error does. We have effectively saturated the accuracy you can extract from this discretization.

Recap

The full script — minus comments — is forty-three lines of Julia. It produces a four-equation ROM that:

  • Captures the 1:2 parametric resonance the FE model exhibits at 24 kHz.
  • Detects two saddle-node bifurcations and one Neimark–Sacker bifurcation.
  • Reproduces the FE reference to near-exact accuracy across the amplitude range.
  • Continues an entire FRF in seconds on a single thread — orders of magnitude faster than time-marching.
