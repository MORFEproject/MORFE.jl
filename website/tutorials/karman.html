Kármán vortex street

What this tutorial covers

  • Assembling a fluid case in one call.
  • Selecting the Hopf pair that spans the manifold.
  • Carrying the Reynolds number as a parametric coordinate.
  • Reading the physics off the reduced dynamics $R$ with parametrise.
  • Tracing the limit-cycle branch, and the lift along it, straight off the ROM.

The fluid backend builds the full-order model for you. To assemble one by hand, see Building a full-order model.

Prerequisites

Follow the installation guide to install MORFE and MORFEFerrite. The example carries its own environment and a committed mesh, so nothing has to be generated first.

Defining the full-order model

The cylinder flow is a first-order ($N=1$) ODE: linearising the incompressible Navier–Stokes equations about the steady base flow and subtracting it leaves the perturbation $\mathbf x = [u';p']$ at the origin, obeying a differential–algebraic system: pressure carries no time derivative, so the mass matrix $\mathbf{B_1}$ is singular.

$$\mathbf B_1\,\dot{\mathbf x} + \mathbf B_0\,\mathbf x = \mathbf F(\mathbf x,\mathbf r) = \underbrace{\mathbf T_1(\mathbf x,\mathbf x)}_{\text{convection}} \,\, + \! \underbrace{\mathbf T_2(\mathbf x,\mathbf r)}_{\text{viscous coupling}} + \!\! \underbrace{\mathbf T_3(\mathbf r)}_{\text{base-flow forcing}}$$

The right-hand side is a sum of multilinear maps $\mathbf T_j$: the quadratic convection $-(u'\!\cdot\!\nabla)u'$, plus two terms carrying the Reynolds dependence. $\mathbf B_1$ is the velocity mass matrix, $\mathbf B_0$ the Jacobian of the steady operator at the base flow.

The external variable $\mathbf r = \eta' = 1/\mathrm{Re} - 1/\mathrm{Re}_0$ is frozen: $\dot{\mathbf r} = 0$. Because $\nu = D/\mathrm{Re}$ enters linearly, one reduction is parametric in Re: it describes a neighbourhood of the expansion point, not a single operating condition.

MORFE sees only $\mathbf B_k$, the callbacks evaluating $\mathbf T_j$, and the eigenvectors, not a mesh or element format. One backend call assembles all of it.

Setup

Follow the installation guide to install MORFE and MORFEFerrite, then load both packages. 

import Pkg
Pkg.activate(@__DIR__; io = devnull)
Pkg.instantiate(; io = devnull)
using MORFE, MORFEFerrite
const NSE = MORFEFerrite.FluidNavierStokes # for incompressible Navier-Stokes
01

State the fluid case

Set the expansion order: 3 for a quick run, 9 to reproduce the reference. The solve is graded, so order 3 reproduces the order-9 coefficients it shares exactly.

fluid_model reads the mesh and assembles the P2/P1 Taylor–Hood spaces, the Newton solve for the base flow $u_0$, and the operators linearised about it. 

order = 3  # Change to 9 for the reference calculation.
case = NSE.fluid_model(joinpath(@__DIR__, "cylinder_flow.msh"); Re = 49.03)

$\mathrm{Re}_0 = 49.03$ is the expansion point, just above critical. DPIM expands about a fixed point, so an unconverged Newton solve poisons every coefficient. The call reports its residual per iteration.

02

Select the Hopf pair

The master modes span the manifold's tangent space: here the Hopf pair, the least-damped conjugate eigenpair of $-\mathbf B_0\, y = \lambda\, \mathbf B_1\, y$. Choosing them is a modelling decision, made here rather than by the backend. case.B is the pair $(\mathbf B_0, \mathbf B_1)$; the descriptor system carries the sign, so the eigensolve takes the tuple whole. 

spectrum = NSE.solve_hopf_eigenproblem(case.B;
    nev = 40, sigma_re = 3.0, sigma_im = 8.0)

master = [spectrum.hopf_index, spectrum.conjugate_index]
outer = setdiff(eachindex(spectrum.eigenvalues), master)
spectrum.eigenvalues[master] # print the Hopf pair

At $\mathrm{Re}_0 = 49.03$ the pair sits just right of the imaginary axis: marginally unstable, shedding at $\omega_0 = 16.86$ rad/s (St ≈ 0.27). With $\eta'$ the reduced coordinates are $(z_1, \bar z_1, \eta')$.

03

Build the MORFE model

build_model turns the case and its spectrum into the physics-independent model and spectral data that parametrise consumes. It computes the left eigenvectors and conjugates a pair's partner rather than solving for it, so the conjugate symmetry holds by construction. 

(; model, spectral, meta) = build_model(case, spectrum;
    master = master, outer = outer, expansion_order = order, scale = 1e-2)
meta.conjugate_permutation # print the conjugate permutation

scale is a mode gauge applied to both eigenvector sides. It changes what $W$ and $R$ mean, and coefficients from two gauges are not comparable, so it is written at the call site. meta.conjugate_permutation comes back [2, 1, 3].

04

Parametrise the invariant manifold

This is where the 57 860 degrees of freedom collapse. Normal-form style keeps only the resonant monomials, and for a Hopf pair that leaves a single complex equation: the Stuart–Landau equation governing the shedding amplitude. 

W, R = parametrise(model, spectral, order;
    resonance = ResonanceConfig(style = :complex_normal_form, tol_relative = 0.1,
        outer_targets = true))
R # print reduced dynamics
$$\dot z_1 = \underbrace{(0.0040 + 16.86\,i)}_{\lambda_1}\,z_1 + \underbrace{(-212.0 - 59.1\,i)}_{c_{101}}\,z_1\eta' + \underbrace{(-0.111 + 0.071\,i)}_{c_{210}}\,z_1|z_1|^2 + \cdots$$

$\lambda_1$ is the linear behaviour of the wake: its real part the growth rate, its imaginary part the shedding frequency $\omega_0$. $c_{101}$ tilts that growth rate as the Reynolds number moves. Setting it to zero, $\mathrm{Re}(\lambda_1) + \mathrm{Re}(c_{101})\,\eta' = 0$, locates the bifurcation at $\mathrm{Re}_c \approx 48.98$. And $\mathrm{Re}(c_{210}) < 0$, so the cubic term bleeds energy out of a growing oscillation: the amplitude saturates instead of running away. That sign is what makes the bifurcation supercritical, and it is why a stable vortex street appears smoothly from $\mathrm{Re}_c$ rather than jumping into existence.

05

Read the bifurcation diagram off $R$

In normal form the limit cycle is a circle $z_1 = \rho e^{i\Omega t}$. Every surviving monomial has $a - b = 1$, so substituting it gives every term of $R_1$ the same factor $e^{i\theta}$ and the phase drops out. Matching $\dot z_1 = (\dot\rho + i\rho\dot\theta)e^{i\theta}$ against it separates amplitude from phase:

$$\dot\rho = \mathrm{Re}\,R_1(\rho, \rho, \eta') \qquad\qquad \Omega = \frac{\mathrm{Im}\,R_1(\rho, \rho, \eta')}{\rho}$$

A limit cycle is a nonzero root of $\mathrm{Re}\,R_1(\rho, \rho, \eta') = 0$, and $\Omega$ read there is its frequency. The whole bifurcation diagram is the roots of a scalar polynomial. 

Re₀ = 49.03
to_Re(η) = 1 / (η + 1 / Re₀)
to_η(Re) = 1 / Re - 1 / Re₀

sweep = (parameter = 1, sheet = :primary, amplitudes = range(0, 4; length = 500),
    parameter_range = (to_η(70.0), to_η(48.0)))

branch = normal_form_branch(R; sweep...)
Re_c = to_Re(branch.parameter[1]) # the ρ = 0 end of the branch is the Hopf point

That polynomial is in $\eta'$ at fixed $\rho$, not the other way round, so each amplitude costs one companion-matrix root-solve. There is no continuation, no step size and no fold to chase: a fold in $\rho$ against Re is just a monotone $\eta'(\rho)$.

Two keywords carry the modelling decisions. parameter_range keeps the sweep physical: the $\eta'$-polynomial also has roots far outside the expansion neighbourhood, at order 3 a second one at $\eta' \approx 0.071$, which is Re $\approx 11$. And sheet = :primary follows the branch out of the Hopf point rather than returning every root, which from order 9 includes a second sheet at large amplitude.

FIG · 02 Every point of the branch is a whole orbit: in the reduced coordinates the limit cycle is the circle $z_1 = \rho e^{i\Omega t}$. Drawn against Re they form a paraboloid growing out of the base flow at $\mathrm{Re}_c$; the grey axis is the steady flow, dashed where it has gone unstable. Drag to orbit. The flat amplitude plots below are this figure seen edge on.
06

A physical observable: the lift

$\rho$ is measured in the normal-form coordinate, whose scale is the mode gauge set in step 03, so it is not a quantity anyone measures. Physical observables are projections of $W$, and cost no full-order work once the manifold is known.

The lift is the pressure traction on the cylinder. Pushed through $W$ it becomes a polynomial in $(z_1, \bar z_1, \eta')$, evaluated around the circular orbit. 

l_free, L0 = NSE.lift_functional(case)
L_coeffs, mset_L = NSE.lift_polynomial(W, l_free)
L = DensePolynomial(L_coeffs, mset_L)

θ = range(0, 2π; length = 257)[1:256]

function max_lift(P, ρ, η)
    base = evaluate(P, [0.0im, 0.0im, complex(η)])
    maximum(abs(real(evaluate(P, [ρ * cis(t), ρ * cis(-t), complex(η)]) - base)) for t in θ)
end

max_lift(L, branch.amplitude[end], branch.parameter[end]) # peak lift at the far end
07

Convergence with expansion order

Truncating $R$ and the projected lift to degree $N$ and reading the branch again gives one curve per order, with no re-solve. Truncating the projected lift rather than $W$ matters: at order 9 that array is ~193 MB, and its projection is a few hundred numbers. 

using CairoMakie

D = case.fom.reference_length      # 0.1 m, the reference length in ν = D/Re
strouhal(Ω) = Ω * D / (2π * NSE.U_MEAN)

curves = map(3:2:order) do N
    b = normal_form_branch(restrict_ReducedDynamics_to_degree(R, N); sweep...)
    P = MORFE.Polynomials.restrict_polynomial_to_degree(L, N)
    (; N, b.amplitude, b.frequency, eta = b.parameter, Re = to_Re.(b.parameter),
        St = strouhal.(b.frequency), lift = max_lift.(Ref(P), b.amplitude, b.parameter))
end

fig = Figure(size = (900, 360))
ax_lift = Axis(fig[1, 1]; xlabel = "Re", ylabel = "max |lift|")
ax_st = Axis(fig[1, 2]; xlabel = "Re", ylabel = "Strouhal number")
for c in curves
    lines!(ax_lift, c.Re, c.lift; label = "order $(c.N)")
    lines!(ax_st, c.Re, c.St; label = "order $(c.N)")
end
axislegend(ax_lift; position = :lt)
fig
One run = every order (exactly)

The solve is graded: degree-$N$ coefficients never depend on degrees $> N$. Zeroing monomials above degree $N$ in the order-9 $(W,R)$ gives the order-$N$ ROM bit-exactly, so the order study costs nothing beyond the single run.

FIG · 03 Maximum lift along the limit cycle vs Re, per truncation order. The horizontal line is the steady base flow (solid = stable, dashed = unstable); branches grow from it at $\mathrm{Re}_c$. Orders coincide near $\mathrm{Re}_c$ and separate with distance.
FIG · 04 Strouhal number $\mathrm{St} = \Omega D / 2\pi U$ along the same branch. It leaves the Hopf point at the linear value 0.268 and rises as the cycle grows, a frequency shift no linear spectrum can give.
Where the expansion stops converging

Where the orders separate, the reduced state has left the region where the expansion converges. Orders 5 and 9 even fold back, which is not physical.

08

Save the ROM and the branch (optional)

The common saver writes $W$, $R$, their coefficient table and a run summary to the example's results directory. The table is what the example's validate.jl checks against the reference, and the branch written beside it is what the figures above are drawn from. 

MORFE.save_rom(joinpath(@__DIR__, "results"), W, R;
    external_system = meta.external_system)

open(joinpath(@__DIR__, "results", "data", "branch.csv"), "w") do io
    println(io, "order,eta,Re,rho,omega,St,max_abs_lift")
    for c in curves, i in eachindex(c.Re)
        println(io, join((c.N, c.eta[i], c.Re[i], c.amplitude[i], c.frequency[i],
            c.St[i], c.lift[i]), ","))
    end
end

Recap

  • One call assembles the mesh, the base flow and the linearised operators; case.B holds $(\mathbf B_0, \mathbf B_1)$.
  • The eigensolve returns its spectrum closed under conjugation, so the Hopf pair can be taken straight from it.
  • Anything entering (multi)linearly can ride along as an external coordinate: here $\eta'$, which makes the ROM parametric in Re.
  • The resonance style decides what survives in $\dot z = R(z)$; normal form keeps the minimal resonant core.
  • The branch comes off $R$ alone, through normal_form_branch; physical quantities are projections of $W$.
