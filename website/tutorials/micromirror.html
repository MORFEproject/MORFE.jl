Scanning torsional micromirror

Literate script — standardized walkthrough ↗

We reduce a 412 308-DOF FE model of a 1×1 mm² silicon torsional micromirror to a four-equation ROM, then continue the frequency-response curve through its 1:2 parametric-resonance window. End-to-end runtime: under thirty seconds on a laptop.

FIG · 01 Geometry & first two torsional modes. The 1:2 ratio is the key: it activates a parametric-resonance branch the linear ROM cannot see.
ROM runs today · FRF continuation is roadmap
The reduction below runs today — it is examples/08_mems_micromirror in MORFEFerrite.jl (mesh.jl → mechanical_model → build_model → parametrise). Only the closing FRF continuation section uses a planned interface and is marked as such.

What you will build

By the end of this tutorial you will have:

  • An FE model of a torsional micromirror loaded from a Gmsh mesh.
  • A 4-equation ROM that captures the 1:2 internal resonance between the first two torsional modes.
  • A continued frequency-response curve showing the parametric-resonance pocket and the pull-in fold.
  • A reconstruction of the physical mirror tilt $\theta(t)$ from the ROM trajectory.
Prerequisites

Julia ≥ 1.10, Ferrite.jl ≥ 1.0, BifurcationKit ≥ 0.4, Plots.jl. Install MORFE.jl and its Ferrite companion MORFEFerrite.jl from GitHub (not yet registered):

using Pkg; Pkg.add(url="https://github.com/MORFEproject/MORFE.jl.git")
Pkg.add(url="https://github.com/MORFEproject/MORFEFerrite.jl.git")
(@v1.11) pkg> add Ferrite BifurcationKit Plots
01

Load the mesh and assemble FE operators

The mesh ships with MORFEFerrite.jl as examples/08_mems_micromirror (generated by mesh.jl from the CAD file). mechanical_model reads it, applies the anchor constraints and assembles the geometrically nonlinear St. Venant–Kirchhoff model.

using MORFE, MORFEFerrite
const SVK = MORFEFerrite.StructuralSVK

# ── CASE ── single-crystal silicon, µm-consistent units
MESH      = joinpath(@__DIR__, "mirror_gimbal.msh")  # from mesh.jl (CAD → Gmsh)
MATERIAL  = SVK.SVKMaterial(E = 170e3, ν = 0.28, ρ = 2.33e-3)
DAMPING   = SVK.RayleighDamping(α = 0.0, β = 0.0)
DIRICHLET = "clamp"        # anchor-pad facetset written by mesh.jl
MASTER    = [1]
ORDER     = 5

# ── Assemble the structural case
case = SVK.mechanical_model(MESH; material = MATERIAL,
    damping = DAMPING, dirichlet = DIRICHLET,
    fe_order = 2, quad_order = 3)

Material parameters target a typical CMOS-MEMS silicon process. This shipped example is conservative, with zero Rayleigh damping.

02

Build the MORFE model and inspect the spectrum

build_model selects the requested master pair and returns the complete spectrum in the separate backend metadata:

(; model, spectral, meta) = build_model(case;
    master = MASTER, expansion_order = ORDER)

meta.spectrum.eigenvalues[meta.master_indices]
Backend data stays separate

meta carries eigenvalues, master indices, forcing information and timings. The reduced result itself remains the physics-independent pair (W, R).

03

Parametrise the invariant manifold

The common MORFE solver consumes the model and spectral data without a structural result wrapper.

W, R = parametrise(model, spectral, ORDER;
    resonance = ResonanceConfig(style = :complex_normal_form, tol = 0.05))

MORFE.save_rom(joinpath(@__DIR__, "results"), W, R)
04

Continue the frequency response

The planned continuation layer will consume the reduced dynamics R and follow the periodic-orbit branch.

frf = continuation(R;  # roadmap API
                       ω_range=(2π*22e3, 2π*26e3),
                       amplitude_init=1e-3,
                       detect_bifurcations=true)

println("  branches found: $(length(frf.branches))")
println("  bifurcations  : $(frf.bifurcations)")
#   branches found: {n_branches}
#   bifurcations  : [Fold @ {ω_fold1}, Fold @ {ω_fold2}, NS @ {ω_ns}]
FIG · 02 Continued FRF. Two folds bound the bistable hysteresis window; the green branch is the 1:2 parametric resonance activated by mode 2.
05

Reconstruct the physical mirror tilt

The ROM lives in normal coordinates. To recover the physical tilt $\theta$, evaluate the parametrisation at a chosen DOF:

tip_node  = find_node(model, [0.5e-3, 0.0, 10e-6])
θ(z)      = reconstruct(rom, z; node=tip_node, component=3)

# Time-march the ROM at the resonant frequency
sol = simulate(rom; Ω=2π*24.18e3, tspan=(0, 2e-3))

plot(sol.t*1e3, rad2deg.(θ.(sol.u));
     xlabel="t [ms]", ylabel="θ [°]")

The reconstruction call traverses $\boldsymbol{\Psi}$ and contracts only the rows for the requested node — no million-DOF intermediate is allocated.

06

Validate against the FE reference

The package ships a small set of FE time-march snapshots for this geometry. validate compares peak amplitudes branch by branch.

ref = load_reference("micromirror_FOM")   # 14 reference points
err = validate(frf, ref)

@info "max relative error : $(round(err.rel_max*100, digits=3)) %"
@info "mean relative error: $(round(err.rel_mean*100, digits=3)) %"
# [ Info: max relative error : {error_max} %
# [ Info: mean relative error: {error_mean} %
That’s within FE discretization noise

Refining the FE mesh changes the reference more than the ROM error does. We have effectively saturated the accuracy you can extract from this discretization.

Recap

The full script — minus comments — is forty-three lines of Julia. It produces a four-equation ROM that:

  • Captures the 1:2 parametric resonance the FE model exhibits at 24 kHz.
  • Detects two saddle-node bifurcations and one Neimark–Sacker bifurcation.
  • Reproduces the FE reference to near-exact accuracy across the amplitude range.
  • Continues an entire FRF in seconds on a single thread — orders of magnitude faster than time-marching.
