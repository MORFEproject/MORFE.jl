Clamped beam with the common MORFE API

Open the notebook ↗

This conservative St. Venant–Kirchhoff example follows the notebook exactly: describe the beam, call build_model, then call parametrise. The committed output uses order 3; changing one line to order 9 reproduces the reference.

Why MORFEFerrite as well as MORFE?

MORFE contains the physics-independent reduction algorithms; MORFEFerrite is separate because it supplies Ferrite mesh handling and finite-element assembly for particular physical models. This keeps the MORFE core independent of any one FEM library or physics backend.

Setup

Activate the environment stored beside the notebook and load both packages. SVK is only a short name for the structural backend; build_model and parametrise are the common MORFE API. 

import Pkg
Pkg.activate(@__DIR__)
using MORFE, MORFEFerrite
const SVK = MORFEFerrite.StructuralSVK
01

State the case

Set the expansion order directly: order = 3 gives the quick notebook run, while changing that line to order = 9 reproduces the conservative reference. mechanical_model then reads the mesh and supplies the required material, damping, and boundary information. The zero Rayleigh coefficients make this case conservative. The finite-element and quadrature orders use their API defaults.

dirichlet = "Dirichlet" is the name of a physical facet group stored in the Gmsh file. The structural backend fixes all three displacement components on those labeled facets to zero, producing the two clamped beam ends. 

order = 3  # Change to 9 for the reference calculation.
case = SVK.mechanical_model(joinpath(@__DIR__, "clamped_clamped_beam.msh");
    material = SVK.SVKMaterial(E = 160e3, ν = 0.22, ρ = 2.32e-3),
    damping = SVK.RayleighDamping(α = 0.0, β = 0.0),
    dirichlet = "Dirichlet")
FIG · 01The gray reference mesh has purple clamped ends. The opaque blue first mode is displayed at $\max |u_y|/t_y = 10$; the green arrow marks node 289's $y$ displacement.
The mesh name is data, not magic

If your mesh uses a different physical-group name for its fixed boundary, pass that name instead of "Dirichlet".

02

Build the common MORFE model

build_model converts the structural case into MORFE's physics-independent model and computes its spectral data. master = [1] selects the first conjugate vibration-mode pair. meta holds auxiliary backend information; the final line below displays the selected eigenvalues. 

(; model, spectral, meta) = build_model(case; master = [1], expansion_order = order)
meta.spectrum.eigenvalues[meta.master_indices]

The clamped–clamped beam of example 01 gives 4 977 free DOFs (40×3×1 hexahedra, quadratic Lagrange).

03

Compute the invariant manifold

parametrise computes the manifold map W and its reduced dynamics R through the chosen order. The resonance setting keeps near-resonant monomials in complex normal form. The final R displays the reduced system. 

W, R = parametrise(model, spectral, order;
    resonance = ResonanceConfig(style = :complex_normal_form, tol = 0.05))
R
The backbone is analytical

For this conservative complex normal form, |z₁| is constant and the oscillation frequency is read directly from the resonant coefficients of R; no continuation or time integration is needed.

FIG · 02Orders 3, 5, 7, and 9 truncate the same order-9 reference. $Delta\omega$ is the change in frequency from the linear eigenfrequency; node 289's transverse displacement is shown as a percentage of the beam thickness.
04

Save the ROM (optional)

The ROM is already available in memory as (W, R). This optional cell writes W, R, their coefficient table, and a summary to results using the common MORFE saver. 

MORFE.save_rom(joinpath(@__DIR__, "results"), W, R);
