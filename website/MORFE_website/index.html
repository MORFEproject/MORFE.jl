Model Order Reduction
for Finite Elements

MORFE.jl computes invariant manifolds of large finite-element models in a single pass — collapsing million-DOF nonlinear oscillators into ROMs of two or four equations that run in microseconds while preserving the true backbone, internal resonances and bifurcations.

01 — Capabilities

What MORFE.jl does.

DPIM computes directly from FE models, invariant manifolds tangent to the chosen eigenmodes. No projection, no slow/fast decomposition, no time-marching.

F.01

Spectral Submanifold

An $n$-dimensional invariant manifold tangent to the chosen eigenspace, with "curved" coordinates — not a Galerkin projection.

F.02

Large-scale FEM

Reads sparse $\mathbf{M}, \mathbf{C}, \mathbf{K}$ directly. Nonlinear terms assembled element-by-element — no full tensor formed. Tested at $>10^6$ DOFs.

F.03

Modal interactions

Arbitrary $p$:$q$ internal resonances detected from the spectrum and retained automatically — 1:2, 1:3, 2:1, and more.

F.04

Quasi-periodic & chaotic forcing

External excitation is a small autonomous system with bounded trajectories. Linear systems can describe periodic or quasi-periodic forcing. Nonlinear dynamics can describe chaotic dynamics.

F.05

Multiphysics

Physics-agnostic interface: structural, electrostatic, MEMS, thermal. Any $p$-th order polynomial ODE on FE matrices is reducible.

F.06

Julia ecosystem

Ferrite.jl, Gridap.jl, BifurcationKit, DifferentialEquations. Open-source, MIT licensed.

04 — In code

Three lines from FE assembly to a runnable ROM.

MORFE consumes the matrices and tensors your FE solver already produces. It returns a symbolic, executable parametrisation of the invariant manifold — including the reduced dynamics and the back-projection to physical DOFs.

Read the tutorial →

cantilever_beam.jl target API 🚧 
using MORFE, Ferrite
# planned API — see docs for current entry points

# 1. Assemble FE operators (M, C, K, quadratic G, cubic H)
model = FEModel("beam.msh"; order=2)
M, C, K, G, H = assemble_nonlinear(model)

# 2. Choose master modes & expansion order
master = [1, 2]              # first bending pair
forcing = Harmonic(ω=0.98, F=0.02)

# 3. Compute the invariant manifold (DPIM, order 7)
rom = parametrise(M, C, K, G, H;
                  master=master, order=7,
                  forcing=forcing)

# 4. Continue the FRF — milliseconds.
frf = continuation(rom; ω_range=(0.85, 1.15))
plot(frf)
