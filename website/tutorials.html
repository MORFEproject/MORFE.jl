Tutorials

Hands-on walkthroughs that take you from a finite-element mesh to a closed, continuable ROM in under fifty lines of Julia. Each tutorial is reproducible — meshes and scripts ship with the package.

Pick your starting point

The quickest way to get MORFE running is to open one of the demo scripts — they work today against the current API. The named tutorials below are written against the planned high-level API and show what the workflow will look like, but are not yet runnable.

Parametrisation method demo

Complete pipeline using the current API: NDOrderModel → eigenproblem → resonance detection → solve_cohomological_problem. Ships in demo/ParametrisationMethod/.

JULIA 1.10+ CURRENT API GITHUB ↗ 
using MORFE

model = NDOrderModel(M, C, K, G)
ep    = compute_eigenproblem(model)
m     = select_master_modes_by_hand(ep, [1,2])
res   = resonance_set_from_graph_style(m)
W, R  = solve_cohomological_problem(
            model, m, res; order=7)
